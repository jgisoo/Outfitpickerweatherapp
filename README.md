
  # Emoji Reaction Picker

  This is a code bundle for Emoji Reaction Picker. The original project is available at https://www.figma.com/design/Lrp31lMR7Qdy0tPbdFOPRu/Emoji-Reaction-Picker.

  ## Setup

  ### 1. Install dependencies
  
  ```bash
  npm i
  ```

  ### 2. Get Weather API Key

  1. Sign up for a free account at [WeatherAPI.com](https://www.weatherapi.com/)
  2. Get your API key from the dashboard
  3. Create a `.env` file in the root directory
  4. Add your API key to the `.env` file:

  ```
  VITE_WEATHER_API_KEY=your_actual_api_key_here
  ```

  ## Running the code

  Run `npm run dev` to start the development server.

  ## Features

  - Real-time weather data from WeatherAPI
  - Dynamic outfit recommendations based on current temperature
  - Hourly weather forecast
  - 7-day weather forecast
  - Location-based weather (uses your current location)
  - Refresh weather data manually
